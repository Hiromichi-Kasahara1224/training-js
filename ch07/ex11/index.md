### 動的配列の push の平均時間計算量
push を n 回呼び出したとき、7.10 の実装では配列を倍々にしていくので
再配置は $\log_2 n$ 回発生する。

各再配置で要素のコピーは $1,2,4,8..., 2^{\log_2 n}$ 回となり、

push を n 回呼び出したときのコピー回数の総和は

$k = log_2 n$とすると、

$S = 2^0+2^1+2^2+2^3...,+2^k = 2^{k+1} -1$

$= 2^{log_2 n+1} - 1 = 2n-1$

となる。

これをn で割ると、平均計算量は 

$(2n-1)/n = 2 - 1/n$

となり、n が大きくなると 2 に近づく。

よって 動的配列の push の平均時間計算量は $O(1)$ となる。
