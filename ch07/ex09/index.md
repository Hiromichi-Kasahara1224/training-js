### "𠮷野家"[0]について

"𠮷野家"[0] => "�"(置換文字) が返る
"吉野家"[0] => "吉"が返る

"𠮷".length => 2  //2つのコードユニット（サロゲートペア）で表現されている
"吉".length => 1  //1つのコードユニットで表現されている

"𠮷".charCodeAt(0).toString(16)) // d842
"𠮷".charCodeAt(1).toString(16)) // dFB7

上記より、
"𠮷"は 0xD842 0xDFB7 のサロゲートペアで表現されているため、
"𠮷野家"[0]を実行すると 0xD842 となり、文字化けとなる。


### "👨‍👨‍👧‍👧"[0]について

"👨‍👨‍👧‍👧"[0] => "�"(置換文字) が返る

"👨‍👨‍👧‍👧"は4つの絵文字と3つのZWJ（ゼロ幅結合子）で表現されている。
また、1つの絵文字は2つのコードユニット（サロゲートペア）で表現されている。

したがって、"👨‍👨‍👧‍👧"[0]を実行すると、最初の絵文字の上位のコードユニットのみが返されるため、文字化けとなる。


### 問題 7.8 で得た絵文字に対する知見

Intl.Segmenter の `granularity: 'grapheme'` を使うことで、今回のような複数のコードユニットからなる文字を1つの文字として扱うことができる。
