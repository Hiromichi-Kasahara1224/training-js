# プログラミング言語や処理系によっては、再帰呼び出しを関数の処理の末尾にする(末尾再帰)ことで、スタックオーバーフローが起こらないよう最適化できるものがある。末尾再帰は何故そのような最適化ができるのか答えなさい。

末尾再帰最適化とは、再帰呼び出しが関数の最後に行われる場合に、スタックフレームを再利用してメモリの使用量を減らす技術

通常の再帰では、関数が自分自身を呼び出すときに、現在の処理が終わっていないため、スタックにその関数の情報（スタックフレーム）を保持しておく必要がある。

一方、末尾再帰では、関数の処理の最後に再帰呼び出しがあるため、呼び出し元の処理がすべて完了しており、スタックフレームを保持する必要がない。

- 通常再帰の例
````
function factorial(n) {
if (n === 0) return 1;
return n * factorial(n - 1); // ← 再帰呼び出しの後に掛け算が残っている
}
````

- 末尾再帰の例
````
function factorialTail(n, acc = 1) {
  if (n === 0) return acc;
  return factorialTail(n - 1, acc * n); // ← 再帰呼び出しが最後の処理
}
````
